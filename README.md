# CRM — система управления оператором сотовой связи

Веб-приложение CRM для автоматизации работы оператора сотовой связи. Система объединяет клиентскую часть и серверную логику, позволяя работать с данными абонентов и управлять системой через административные интерфейсы.

## Основные возможности

* управление данными абонентов;
* работа с пользовательским личным кабинетом;
* административная панель для управления системой;
* серверная часть на Django;
* веб-интерфейс на HTML, CSS и JavaScript;
* работа с базой данных;
* разделение frontend и backend на отдельные модули.

## Технологии

* **Python / Django** — backend и административная часть;
* **HTML5** — структура веб-интерфейса;
* **CSS3** — стилизация и оформление;
* **JavaScript** — клиентская логика и взаимодействие с интерфейсом;
* **SQL / база данных** — хранение данных CRM.
